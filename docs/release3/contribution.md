# Bidrag i prosjektet

Dette dokumentet beskriver hva hvert gruppemedlem har bidratt med gjennom hele prosjektet. Vi har jobbet i par i release 2 og 3, og byttet på hvem vi har vært med. Arbeid som er gjort i par, er oppført hos begge. I release 3 gikk vi sammen gjennom og ble enige om issuene i starten av hver sprint, før de ble opprettet på GitHub. I tillegg har alle deltatt i planlegging, gruppemøter, dokumentasjon og review av hverandres kode.

## Jesper Barosen

I release 1 satte Jesper opp flermodulstrukturen i Maven med JaCoCo, fjernet malprosjektene, laget fillagring og siden for å vise et emne med tester og feilhåndtering, og opprettet og finpusset dokumentasjonen for release 1. I release 2 laget Jesper JSON-lagringen i file-modulen med Tias, koblet skjermene til fagvalget med Mathea og skrev tester for alle modulene med William. Med Rebecca og Nicole laget Jesper lesing av anmeldelser, klasse-, sekvens- og pakkediagrammene og teamrefleksjonen, og dokumenterte arbeidsflyten og lagringsmodellen. I release 3 bygde Jesper REST-serveren med Spring Boot og endepunktene for emner og anmeldelser med Mathea. Med Rebecca koblet Jesper JavaFX-klienten til REST-API-et, testet den mot ekte server og laget «Mine anmeldelser» og «Fortsett som gjest», og med Rebecca og Nicole sikret Jesper lagringen mot tap av data. Jesper laget endring og sletting av anmeldelser med William og Mathea, registreringen i klienten med Tias og Nicole, og «Vis passord», profilknappen, bærekraftsrefleksjonen og challenges.md med Nicole. Jesper ga også ui engelske navn med William og skrev REST-dokumentasjonen sammen med hele gruppen.
